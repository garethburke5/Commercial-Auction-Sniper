# History V2 rollout notes

The live entrypoint is intentionally a thin wrapper during rollout. The previous app.py is preserved byte-for-byte as legacy_app.py. The wrapper only intercepts the exact Google history-search href generated by the legacy card renderer; confident internal History V2 matches route to /History?address=..., while unmatched properties retain the existing Google fallback. This keeps the rest of the production board unchanged and makes rollback a one-file ref change.
