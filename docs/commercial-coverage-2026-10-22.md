## Changes in this release

- Knight Frank: replace empty-shell discovery with the site’s published search form; paginate and reconcile stated event totals. Preserve guides separately from results.
- Shepherd, Maggs & Allen, Prime, Shonki Bros and Hollis Morgan: add maintained collectors to the existing six-hour pipeline, with per-lot inspection outcomes and explicit detail failures. Production counts must be verified after the scan.
- Prime: no copied photography or marketing narrative; current bids never become guides or achieved prices. External descriptions are used for factual classification, with original summaries published. Missing fields remain missing.
- Classification: a leasehold flat inside a mixed-use building is not the whole mixed-use investment. Hollis Morgan classification uses the accommodation section, avoiding nearby cafes and developments.
- Owner-only dashboard: comparable official/captured counts, missing links, duplicates, last successful collection, errors, historical holdings and inspected past-result coverage. Unknown denominators stay unknown. Allsop, Acuitus and Barnett Ross emit explicit URL/date evidence for measured catalogue scopes.
- Monitoring: hourly freshness now checks individual failed/degraded sources and stale last-success timestamps as well as the overall snapshot. These are operational alarms, not a claim that every source is healthy.
- Cottons: tolerate only identical duplicated rows in official results; conflicting lot evidence still fails. September/October result import adds 83 appearances (7,283 → 7,366); no guides or commercial sector assignments invented from result prices. Existing rotating archive tasks continue.
